# Market Studio — 나무증권 시세 대시보드

나무 PLUG OpenAPI의 읽기 전용 시세를 이용하는 로컬 웹 프로토타입입니다. 매매·계좌·잔고 API는 호출하지 않습니다.

## 현재 구현 상태 (2026-11-22 정리)

- 국내 주식·ETF·ETN 현재가, 전일 종가 대비 등락률, 최대 100개 일봉, 이동평균과 차트 확대·축소.
- 공식 종목마스터에서 2026-11-21에 생성한 `master.json`의 4,332개 대상 히트맵. REST 요청을 순차 처리하며 진행률과 실패를 표시합니다. 목록은 자동 갱신되지 않습니다.
- 다우존스 `.DJI`, AAPL 시세 응답의 `currency_prc` 환율 필드. 환율은 별도 실시간 환율 호가나 고시환율로 검증한 값이 아닙니다.
- 코스피·코스닥·S&P 500은 미완료입니다. 후보 `.KS11`, `.KQ11`, `.SPX`는 유효한 응답을 확인하지 못했습니다.
- 2026-11-21 ego-lite에서 4,332개 모두 조회 성공을 확인했습니다. 이는 당시 한 번의 수집 결과이며 현재 데이터 상태를 보장하지 않습니다. 종목별 수신 시각이 달라 동시 시점 스냅샷이 아닙니다.

## 실행

Node.js가 설치된 PC에서 PowerShell을 열고 이 폴더로 이동한 뒤 실행합니다.

```powershell
node .\start.mjs
```

나무 PLUG 앱키와 시크릿을 각각 직접 입력합니다. 입력값은 화면에 표시되지 않습니다. 또는 Node.js 22.13 이상에서 `.env.example`을 `.env`로 복사하고 `NHPLUG_APP_KEY`, `NHPLUG_APP_SECRET`을 직접 채운 뒤 `node --env-file=.env server.mjs`로 실행할 수 있습니다. `.env`는 이 폴더의 `.gitignore`에 의해 Git에서 제외됩니다. 브라우저에서 http://127.0.0.1:8766/ 을 열고, 종료할 때는 터미널에서 Ctrl+C를 누릅니다. 서버를 키 없이 `node .\server.mjs`로 시작하면 로컬 웹 연결 화면을 이용할 수 있습니다.

인증정보는 Git·채팅에 넣지 마세요. `.env` 방식은 키를 로컬 파일에 평문으로 저장하므로 신뢰할 수 있는 기기에만 보관하고 공유·업로드하지 마세요. 서버는 키와 토큰을 프로세스 메모리에 보관합니다. 웹 연결 방식에서는 브라우저 입력란과 로컬 요청을 거칩니다. 토큰은 재시작 시 재발급되므로 불필요한 재시작을 피하세요. 로컬 서버는 loopback에만 바인딩되며 신뢰할 수 있는 PC에서 사용하세요.

## 데이터와 DB

이 프로젝트는 SQLite나 Cloudflare D1에 연결하지 않습니다. `master.json`은 정적 종목 목록이고 시세와 히트맵 결과는 서버·브라우저 메모리에만 있습니다. 관심종목은 브라우저 localStorage에 저장됩니다. 새로고침하면 히트맵을 처음부터 다시 수집하며 탭을 닫으면 수집이 중단됩니다. 따라서 집 PC에 DB를 설치할 필요는 없지만, 직장 PC의 히트맵 결과와 관심종목이 자동으로 넘어가지는 않습니다.

별도 `stock-trading` 프로젝트에는 SQLite 파일 `data/trading.db`와 Cloudflare D1 `sarah-ai-db` 설정이 있으나, Market Studio와 연결되어 있지 않습니다. 2026-11-22 읽기 전용 확인 결과 원격 D1에는 0003_kiwoom_market_data.sql 마이그레이션이 미적용이며 stocks와 price_history는 각각 0행입니다. 별도 주차장 D1과 혼동하지 마세요.

## 구성

- `server.mjs`: 로컬 HTTP 서버, 나무 인증·읽기 전용 조회 및 350ms 요청 간격.
- `app.js`, `index.html`: 대시보드와 순차 히트맵 수집.
- `master.json`: 공식 마스터의 2026-11-21 기준 스냅샷.
- `start.mjs`: 터미널에서 키를 가려 입력받는 실행기.
- `HANDOFF.md`: 다음 작업과 검증 상태.

서버가 로컬에 정상 실행된 경우 `GET /api/status`, `/api/stock?code=005930`, `/api/quote?code=005930`, `/api/fx`, `/api/index?symbol=.DJI`로 확인할 수 있습니다. 서버 응답의 수신 시각은 거래소 체결 시각이 아닙니다.
